Investing.com → Markets Briefing

One-time setup. Your Investing.com login stays in Chrome; this page only needs a GitHub token so the extension can save the watchlist file to your repo.

Make one yourself (it stays on this computer, in this extension only):
  1. Open github.com → Settings → Fine-grained tokens → Generate new token.
  2. Repository access: Only select repositories → markets-briefing.
  3. Permissions → Repository permissions → Contents: Read and write. Nothing else.
  4. Generate, copy, paste it above, Save.
Leave as is unless you keep several watchlists; then paste the address of the professor's one.
